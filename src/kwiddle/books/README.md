# Kwiddle book library

Place complete supported book files in this folder. Subfolders are scanned automatically, and the library refreshes while Kwiddle is running.

For the best offline experience, use self-contained ODT or FODT files with embedded images and formatting. The reader also accepts every format listed by `kwloader.SUPPORTED_EXTENSIONS`.

This README is documentation only; it is not shown as a book in the library.
